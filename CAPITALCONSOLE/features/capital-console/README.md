# Capital Console Feature (base)

Este directorio queda preparado para crecer por módulos internos:

- `components/`: componentes del feature (UI específica, no global).
- `hooks/`: hooks locales del feature.
- `screens/`: composición de pantallas del feature.
- `schemas/`: validaciones y contratos del feature.

> En esta fase solo se inicializa la base, sin lógica de negocio completa.
